
# Digital Twin Introduction

Digital Twin is a high performance ledger purpose built for real-time financial operations.

It enables 24X7 money movement and balance inquiries whether a Core banking system is up or down.

It supports fiat and digital asset balances, transaction authorization, balance management, stablecoin and blockchain related flows with continuous availability.

## Cloud native and event-driven

It is micro-services and event-driven software installed in the cloud allowing financial institutions to scale up or down based on demand. It is intentionally designed to be lightweight yet resilient so it can efficiently handle the critical task of transaction authorization. It is not intended to be a place to create new policies or products. It is simply enforcing the rules and policies that are maintained on the Core.

To that end, it's highly configurable. The accounts, products, transaction codes and authorization rules are replicated from the Core to Digital Twin.

Digital Twin can host many different types of accounts. Examples include, but aren't limited to:

- DDA
- Savings
- Credit card
- Loan
- Loyalty points
- Cryptocurrency

It is multi-currency, multi-timezone and multi-decimal point so can accommodate any type of cryptocurrency.

It publishes transaction information to events that can be consumed by downstream systems. For example, information in events could be used to support postings back to the Core, to enhance fraud systems, or to feed a data lake being used to leverage AI applications and agents.

Core banking systems handle many complex tasks. Adding Digital Twin to the tech stack lets the Core continue to be the System of Record, a place to manage authorization rules, regulatory and compliance functions and related.

In effect, Digital Twin can enable a Core banking system to become real-time.

## Proven performance at scale

Digital Twin has demonstrated the ability to process:

- More than 12,000 transactions per second across 145 million accounts
- More than 3,400 transactions per second on a single account

This performance profile supports high-volume real-time payment and digital asset use cases.

## In summary

Digital Twin:

- Enables real-time, 24×7 transaction authorization
- Enhances — not replaces — the core banking system
- Eliminates dependence on batch windows and maintenance cycles
- Provides the foundation for digital assets and future rails
